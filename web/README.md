# read 应用 - 前端显示设计

## 版本更新说明

**版本 = 3.0**

1. **数据库增加 share_id 和 status 字段**：articles 表新增 `share_id`（8位UUID，用于反爬和分享）和 `status`（下载状态：-1未提取/0失败/1成功）。文章阅读页通过 `share_id` 而非自增 `id` 打开，防止遍历攻击。

2. **Token 认证**：index.html 主页面增加 token 认证，token 保存在本地 `config.json` 中（8位随机字符串），URL 需携带 `?token=xxx` 参数才能访问。所有 API 请求自动附加 token。

3. **删除功能**：文章控件第三行增加「删除」按钮，点击确认后删除文章记录、关联标签/关键词记录，并同步删除本地文件夹。

4. **article.html 纯净阅读**：去掉「返回列表」和「原文链接」控件；后端推送正文时自动截取——从 markdown 中「采集时间」行的下一行开始，只推送正文内容，不显示标题、来源、标签等元信息。

## 后端 API 设计（Flask）

| 接口 | 方法 | 认证 | 功能 |
|:---|:---|:---|:---|
| `/` | GET | ✓ token | 主页面（index.html） |
| `/api/labels` | GET | ✓ token | 获取所有标签（树形结构） |
| `/api/articles` | GET | ✓ token | 按标签 OR 查询获取文章列表 |
| `/api/article/<id>` | GET | ✓ token | 获取单篇文章 Markdown（API） |
| `/api/article/<id>` | DELETE | ✓ token | 删除文章及相关记录和本地文件 |
| `/api/article/<id>/tags` | POST | ✓ token | 更新文章标签 |
| `/api/file/<id>/<path>` | GET | ✓ token | 读取文章目录下的图片等文件 |
| `/article/<share_id>` | GET | ✗ | 独立文章阅读页面（通过 share_id） |

---

## Token 认证机制

- 启动时自动检查 `config.json`，不存在则生成8位随机 token 并写入
- 访问主页面和 API 时，URL 必须携带 `?token=xxx` 参数
- 前端从当前 URL 提取 token，所有 fetch 请求自动附加
- 示例访问地址：`http://localhost:5081/?token=a1b2c3d4`

## 文章列表项结构

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 文章标题（16px，加粗）                                        [摘要]    │  ← 第一行
│ [关键词1][关键词2]...          [分类标签A][分类标签B]...                   │  ← 第二行
│ 来源: xxx    2026-06-08                    [原文链接]  [删除]          │  ← 第三行
└──────────────────────────────────────────────────────────────────────────┘
```

### 第一行：标题 + 摘要按钮

| 元素 | 样式 | 交互 |
|:---|:---|:---|
| 标题 | 16px, font-weight:600, 单行省略 | **点击 → 新窗口打开 `/article/<share_id>`** |
| 摘要按钮 | 8pt, 蓝框白底 | **点击 → 右侧边栏显示该文章摘要详情** |

### 第二行：关键词(左) + 分类标签(右)

| 元素 | 样式 | 来源 |
|:---|:---|:---|
| 关键词标签 | 10px, 蓝底蓝字 | `article_analysis.keywords`，逗号分隔，最多5个 |
| 分类标签 | 10px, 灰底灰字 | `article_labels` 关联的标签 |

### 第三行：来源日期(左) + 操作按钮(右)

| 元素 | 样式 | 交互 |
|:---|:---|:---|
| 来源 | 8pt, 灰色 | 静态显示 |
| 日期 | 8pt, 浅灰色 | 静态显示 |
| 原文链接 | 8pt, 蓝色加粗 | 点击新标签页打开原始 URL |
| 删除 | 8pt, 灰框灰字，hover 红底红字 | 点击确认后删除文章及关联数据 |

## 删除功能

**删除范围**：
1. `article_labels` 表中该文章的标签关联记录
2. `article_analysis` 表中该文章的分析记录
3. `articles` 表中该文章的主记录
4. 本地 `local_path` 文件夹（含 article.md 和 images）

**前端交互**：点击删除按钮 → 确认弹窗 → 发送 DELETE 请求 → 成功后刷新文章列表，同时清空右侧边栏（如果当前显示的是被删文章）。

---

## 右侧边栏：文章摘要详情

触发条件：**点击文章项中的「摘要」按钮**

显示内容：标题、来源、日期、关键词、分类标签、摘要正文、操作链接（查看原文 / 阅读全文）。

## 独立文章阅读页面（article.html）

**访问方式**：`/article/<share_id>`，无需 token。

**页面内容**：仅渲染文章正文（Markdown 转 HTML），不显示任何元信息：
- 去掉「返回列表」按钮
- 去掉「原文链接」
- 不显示标题、来源、采集时间、标签
- 后端自动从 markdown 中截取正文（从「采集时间」行的下一行开始）

```
│                                             │
│  更多段落...                                │
│                                             │
└────────────────────────────────────────────┘
```

## 数据库表结构

### articles（文章主表）

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| id | INTEGER PRIMARY KEY AUTOINCREMENT | 自增主键 |
| url | TEXT UNIQUE NOT NULL | 原始 URL |
| title | TEXT | 文章标题 |
| local_path | TEXT | 本地保存路径 |
| created_at | TEXT | 收录时间（ISO 格式） |
| source | TEXT | 来源类型 |
| status | INTEGER DEFAULT 1 | 下载状态：-1未提取 / 0失败 / 1成功 |
| share_id | TEXT UNIQUE | 8位 UUID，用于阅读页反爬 |

## 技术栈

| 层级 | 技术 | 理由 |
|:---|:---|:---|
| 后端 | Flask + SQLite | 轻量，与 collector 共用采集库 |
| 前端 | 原生 HTML + CSS + JS | 无需构建工具 |
| Markdown 渲染 | marked.js (CDN) | 成熟稳定 |
| 认证 | URL token + 本地 JSON | 简单有效，适合少数人使用 |

## 启动方式

```bash
cd read
python app.py
```

首次启动会自动生成 `config.json`，其中包含8位随机 token。访问地址：

```
http://localhost:5081/?token=<config.json 中的 token 值>
```
