## 后端 API 设计（Flask）

| 接口 | 方法 | 功能 |
|:---|:---|:---|
| `/api/labels` | GET | 获取所有标签（树形结构） |
| `/api/articles` | GET | 按标签筛选获取文章列表（含摘要、关键词） |
| `/api/article/<id>` | GET | 获取单篇文章的 Markdown 内容 |
| `/api/article/<id>/tags` | POST | 给文章打标签/修改标签 |
| `/api/file/<id>/<path>` | GET | 读取文章目录下的图片等文件 |

### 更新内容：

1. **三栏布局**：修改为左中右三列视图，左侧显示标签筛选、中部显示文章列表、右侧显示文章摘要详情。

2. **可拖拽分割线**：左右两根分割线支持鼠标拖拽调整各栏宽度，默认比例 20% / 60% / 20%，最小宽度限制左栏≥180px、中栏≥300px、右栏≥200px。

3. **文章控件重构**：文章列表项改为三行结构——第一行标题（16px加粗）+「摘要」按钮，第二行关键词标签（左）+分类标签（右），第三行来源日期（左）+原文链接（右，蓝色加粗8pt）。

4. **标签查询改为 OR/并集**：勾选多个标签时，显示包含任一选中标签的文章，而非必须同时满足所有标签。

5. **右侧摘要边栏**：点击文章项中的「摘要」按钮，在右侧边栏显示该文章的完整摘要、关键词、分类标签及操作链接（查看原文、阅读全文）。

## 文章列表项结构

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 文章标题（16px，加粗）                                           [摘要]    │  ← 第一行
│ [关键词1] [关键词2]...          [分类标签A][分类标签B]...                   │  ← 第二行
│ 来源: xxx    2026-06-08                                      原文链接     │  ← 第三行
└──────────────────────────────────────────────────────────────────────────┘
```

### 第一行：标题 + 摘要按钮

| 元素 | 样式 | 交互 |
|:---|:---|:---|
| 标题 | 16px, font-weight:600, 单行省略 | **点击 → 新窗口打开文章阅读页** |
| 摘要按钮 | 8pt, 蓝框白底, hover蓝底白字 | **点击 → 右侧边栏显示该文章摘要详情** |

### 第二行：关键词(左) + 分类标签(右)

| 元素 | 样式 | 来源 |
|:---|:---|:---|
| 关键词标签 | 10px, 蓝底蓝字, 圆角3px | `article_analysis.keywords`，逗号分隔，最多显示5个 |
| 分类标签 | 10px, 灰底灰字, 圆角3px | `article_labels` 关联的标签 |

### 第三行：来源日期(左) + 原文链接(右)

| 元素 | 样式 | 说明 |
|:---|:---|:---|
| 来源 | 8pt, 灰色 | `articles.source` |
| 日期 | 8pt, 浅灰色 | `articles.created_at`，格式 YYYY-MM-DD |
| 原文链接 | 8pt, 蓝色加粗 | 点击新标签页打开 `articles.url` |

## 左侧边栏：标签筛选

### 标签树

- 一级标签可展开/收起二级标签
- 点击复选框选中/取消二级标签
- **多标签查询为 OR/并集**：勾选多个标签，显示包含**任一**选中标签的文章

### 已选标签

- 底部显示已选标签为蓝色药丸
- 点击药丸可删除该筛选条件
- 「清空」按钮一键清除所有选中标签

## 标签查询 SQL（OR/并集）

```sql
-- 多标签筛选：文章包含任一选中标签即可（OR/并集）
SELECT a.id, a.url, a.title, a.local_path, a.created_at, a.source,
       aa.summary, aa.keywords
FROM articles a
LEFT JOIN article_analysis aa ON a.id = aa.article_id
WHERE a.id IN (
    SELECT DISTINCT article_id FROM article_labels
    WHERE label_id IN (?, ?, ?)  -- 选中的标签ID列表
)
ORDER BY a.created_at DESC;
```

## Markdown 图片路径处理

`article.md` 中的图片引用：
```markdown
![001.jpg](images/001.jpg)
```

转换为可访问 URL：
```
/api/file/<article_id>/images/001.jpg
```

后端提供文件读取接口，从 `local_path` 下读取图片返回。

## 技术栈

| 层级 | 技术 | 理由 |
|:---|:---|:---|
| 后端 | Flask + SQLite | 轻量，与 collector 共用采集库 |
| 前端 | 原生 HTML + CSS + JS | 无需构建工具，直接运行 |
| Markdown 渲染 | marked.js (CDN) | 成熟稳定，支持图片 |
| 标签树 | 原生 JS 递归渲染 | 数据量小，无需复杂框架 |
